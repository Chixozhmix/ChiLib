# Что это?
Chi's Lib - простая библиотека для моих модов, которую я использую, чтобы всегда иметь доступ к нужным мне функциям.

# Что может?
Библиотека имеет внутри себя утилиты, которые позволяют облегчить работы с некоторыми моментами или просто делают ее более удобной.

Среди функционала:
- Упрощение регистрации эффектов.
- Упрошенное создание музыки для боссов.
- Утилиты предметов.
- Утилиты сущностей.
- Упрошенная регистрация рецептов зелий.
- Фикс отображения зелий в меню JEI.
- Утилиты заклинаний.
- Утилиты оверлея.
- Утилиты для партиклов.
- Отслеживание первого захода в мир.
- Таймер игрока.
- Помощник тиков для событий, которые должны идти последовательно один за другим.
- Многое другое.

# Будущее
Библиотека постоянно расширяется, так что в будущем здесь будет куда больше функционала. Конечно, в первую очередь все это я делал для себя, но если вы найдете здесь что-то полезное лично для вас - мнея это порадует.
